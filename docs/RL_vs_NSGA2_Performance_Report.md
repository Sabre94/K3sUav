# RL vs NSGA-II 覆盖率调度算法性能对比报告

> 测试日期: 2024年
> 测试环境: UAV 无人机编队覆盖率调度系统
> 测试节点数: 20/30/50
> 测试编队: 随机分布、网格编队、线性编队、环形编队、聚类分布
> 目标覆盖率: 70%、80%、85%、90%、95%

---

## 1. 算法简介

### 1.1 RL (强化学习) 算法

- **类型**: Policy Gradient (REINFORCE)
- **网络结构**: 12 → 128 → 128 → 1 (MLP)
- **特点**:
  - 训练后推理速度极快（毫秒级）
  - 支持任意编队规模和队形
  - 单次推理给出一个解

### 1.2 NSGA-II (多目标遗传算法)

- **类型**: 非支配排序遗传算法
- **种群大小**: 50
- **迭代代数**: 100
- **特点**:
  - 提供Pareto前沿多个解
  - 多目标优化（覆盖率、节点数、电量、延迟）
  - 能找到更节省节点的解

## 2. 总体统计概览

| 指标 | RL | NSGA-II | 对比 |
|:----:|:----:|:-------:|:----:|
| 测试场景总数 | 75 | 75 | - |
| 平均执行时间 | **33.6ms** | 15.5s | RL快461倍 |
| 平均选中节点数 | 25.6 | **19.9** | NSGA2省22% |
| 覆盖率达标率 | **100%** | **100%** | 持平 |

### 核心结论

```
⚡ 速度:    RL 比 NSGA-II 快约 461 倍
📊 覆盖率:  两者都能 100% 满足约束要求
📦 节点:    NSGA-II 平均少用 5.8 个节点
```

## 3. 按目标覆盖率统计

| 目标覆盖率 | RL平均时间 | NSGA2平均时间 | 加速比 | 节点效率 |
|:----------:|:----------:|:-------------:|:------:|:--------:|
| 70% | 26.3ms | 10.9s | **416x** | NSGA2省 |
| 80% | 31.4ms | 14.2s | **452x** | NSGA2省 |
| 85% | 31.9ms | 15.8s | **494x** | NSGA2省 |
| 90% | 36.9ms | 17.5s | **474x** | NSGA2省 |
| 95% | 41.7ms | 19.2s | **460x** | NSGA2省 |

### 趋势分析

- 目标覆盖率越高，两种算法执行时间都增加
- RL时间增长缓慢（26ms → 42ms）
- NSGA-II时间增长明显（10.9s → 19.2s）
- 加速比在85%覆盖率时达到峰值（494x）

## 4. 按节点数量统计

| 总节点数 | RL平均时间 | NSGA2平均时间 | 加速比 | NSGA2节省节点 |
|:--------:|:----------:|:-------------:|:------:|:-------------:|
| 20 | 12.8ms | 5.9s | **463x** | 29.2% |
| 30 | 25.5ms | 12.2s | **478x** | 36.1% |
| 50 | 62.7ms | 28.4s | **454x** | **47.4%** |

### 趋势分析

- 节点数越多，NSGA-II节省的节点比例越高
- 50节点场景下，NSGA-II能省近一半的节点
- 加速比保持稳定（454x ~ 478x）

## 5. 按编队类型统计

| 编队类型 | RL平均时间 | NSGA2平均时间 | 加速比 | 效率优胜者 |
|:--------:|:----------:|:-------------:|:------:|:----------:|
| 随机分布 | 35.1ms | 22.0s | **627x** | 相当 |
| 网格编队 | 37.6ms | 20.2s | **537x** | 相当 |
| 线性编队 | 31.3ms | 9.3s | 296x | **NSGA-II** |
| 环形编队 | 31.4ms | 16.5s | **524x** | **NSGA-II** |
| 聚类分布 | 32.8ms | 9.6s | 294x | **NSGA-II** |

### 编队特点分析

| 编队类型 | 特点 | 最适合算法 |
|:--------:|:-----|:----------:|
| 随机分布 | 节点分散，覆盖重叠少 | 两者相当 |
| 网格编队 | 均匀分布，覆盖规则 | 两者相当 |
| 线性编队 | 节点排列成线，重叠多 | NSGA-II (省更多节点) |
| 环形编队 | 节点围成圈，中心空 | NSGA-II |
| 聚类分布 | 多个聚类，局部密集 | NSGA-II (省更多节点) |

## 7. 适用场景建议

| 场景 | 推荐算法 | 理由 |
|:----:|:--------:|:-----|
| 🚀 **实时调度 / 在线决策** | **RL** | 毫秒级响应，适合动态环境 |
| 💰 **节点资源敏感 / 成本优先** | **NSGA-II** | 能找到更省节点的解 |
| 📋 **离线规划 / 方案比选** | **NSGA-II** | Pareto前沿提供多种方案 |
| 🔄 **大规模部署 / 频繁调整** | **RL** | 预训练后推理极快 |
| ⚡ **边缘计算 / 资源受限** | **RL** | 计算量小，适合嵌入式 |
| 🎯 **高精度优化 / 质量优先** | **NSGA-II** | 多目标优化更全面 |

## 8. 技术细节

### 8.1 RL 算法参数

```go
RLConfig{
    HiddenSize:      128,        // 隐藏层大小
    NumHiddenLayers: 2,          // 隐藏层数量
    LearningRate:    0.005,      // 学习率
    Gamma:           0.99,       // 折扣因子
    TargetCoverage:  0.85,       // 训练目标覆盖率
    CoverageRadius:  500.0,      // 覆盖半径(米)
    GridDensity:     30,         // 网格密度
}
```

### 8.2 NSGA-II 算法参数

```go
NSGA2Config{
    PopulationSize: 50,          // 种群大小
    Generations:    100,         // 迭代代数
    CrossoverRate:  0.9,         // 交叉概率
    MutationRate:   0.1,         // 变异概率
    CoverageRadius: 500.0,       // 覆盖半径(米)
    GridDensity:    50,          // 网格密度
}
```

### 8.3 覆盖率计算

两种算法使用**相同的覆盖率计算方法**：

1. 将GPS坐标转换为平面坐标（米）
2. 在覆盖区域生成网格采样点
3. 计算被任意节点覆盖的采样点数量
4. **去重叠**：同一点被多个节点覆盖只计算一次
5. 覆盖率 = 被覆盖点数 / 总采样点数

## 9. 结论

### 9.1 核心发现

1. **速度**: RL比NSGA-II快约**461倍**
2. **达标率**: 两者都能**100%**满足覆盖率约束
3. **节点效率**: NSGA-II平均**少用5.8个**节点
4. **编队适应性**: NSGA-II在线性/聚类编队中节点效率更高
